Watch history

Your watched and in-progress status for every stream is stored locally in your browser. You can back it up or move it to another device.

Editor Mode

Enable Editor Mode

Adds an Edit Entry option to every stream card's ··· menu and a New Entry button at the top. Changes are saved locally in your browser until exported. Disabling Editor Mode will hide all local changes.

Export

Download your local edits as a JSON file you can submit to the site's GitHub repository.

Clear editor data

Permanently delete all local edits — new entries, modifications, and deletions. This cannot be undone.

Editor Mode Edit Colors

Select a tag to edit its color
